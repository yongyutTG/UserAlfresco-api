UserAlfresco API

API Gateway สำหรับเรียก Alfresco ตามสิทธิ์ของ user ที่ login จริง โดย client ต้อง login เพื่อรับ accessToken แล้วแนบเป็น Bearer token ทุกครั้งที่เรียกกลุ่ม /user-api/alfresco/*

UserAlfresco-api โปรเจคนี้ default ใช้ port 3001

โปรเจคนี้เหลือเฉพาะ backend API และหน้าเอกสาร API ส่วนหน้าบ้านจริงแยกไปอยู่โปรเจค Alfresco

โปรเจคนี้ใช้ Authorization: Bearer <accessToken> เป็นหลัก ไม่ใช้ cookie session สำหรับ API

สรุป Endpoint ทั้งหมด

Method Path Token ใช้ทำอะไร
GET/healthไม่ต้องตรวจสอบว่า backend เชื่อม Alfresco ได้หรือไม่
POST/auth/loginไม่ต้องlogin ด้วย Alfresco username/password เพื่อรับ accessToken
GET/auth/meต้องดู session ปัจจุบันของ token
POST/auth/logoutต้องลบ session token ฝั่ง backend
GET/user-api/alfresco/foldersต้องดู folder ลูกชั้นเดียวใต้ path ที่ระบุ
GET/user-api/alfresco/folders/treeต้องดู folder ย่อยหลายชั้นใต้ path ที่ระบุ
GET/user-api/alfresco/documentsต้องlist เอกสารใต้ folder รวม folder ย่อย
GET/user-api/alfresco/documents/searchต้องค้นหาเอกสารด้วย q หรือ exactName
GET/user-api/alfresco/documents/locationต้องดู parent path ของไฟล์ด้วย query id
GET/user-api/alfresco/documents/:id/locationต้องดู parent path ของไฟล์แบบ route เก่า
PATCH/user-api/alfresco/documents?id=...ต้องแก้ชื่อไฟล์ แบบแนะนำสำหรับ Alfresco id ที่มี ;1.0
PATCH/user-api/alfresco/documents/:idต้องแก้ชื่อไฟล์ผ่าน path parameter
GET/user-api/alfresco/documents/:id/contentต้องเปิดหรือดาวน์โหลดไฟล์

1. Health Check

GET http://localhost:3001/health

ใช้เช็ก backend และข้อมูล server Alfresco เบื้องต้น

2. Login

POST http://localhost:3001/auth/login
Content-Type: application/json

{
  "username": "alfresco_user",
  "password": "alfresco_password"
}

Response จะได้ accessToken สำหรับใช้เป็น Bearer token

{
  "tokenType": "Bearer",
  "accessToken": "ACCESS_TOKEN",
  "expiresInMs": 28800000,
  "username": "alfresco_user"
}

3. Current User

GET http://localhost:3001/auth/me
Authorization: Bearer <accessToken>

4. Logout

POST http://localhost:3001/auth/logout
Authorization: Bearer <accessToken>

5. List folders ชั้นเดียว

GET http://localhost:3001/user-api/alfresco/folders?path=/Sites/tg-saving/documentLibrary
Authorization: Bearer <accessToken>

ใช้ดู folder ลูกโดยตรงของ path ที่ส่งมา

6. List folder tree

GET http://localhost:3001/user-api/alfresco/folders/tree?path=/Sites/tg-saving/documentLibrary&maxDepth=2
Authorization: Bearer <accessToken>

ใช้ดู folder ย่อยหลายชั้น Response มีทั้ง folders แบบ flat list และ tree แบบ parent/children

7. List documents

GET http://localhost:3001/user-api/alfresco/documents?folderPath=/Sites/tg-saving/documentLibrary/การเงิน&maxItems=20&skipCount=0
Authorization: Bearer <accessToken>

ถ้าไม่ส่ง q จะเป็นการ list เอกสารทั้งหมดใต้ folder นั้น รวม folder ย่อยด้วย CMIS IN_TREE

8. Search documents แบบบางส่วน

GET http://localhost:3001/user-api/alfresco/documents/search?folderPath=/Sites/tg-saving/documentLibrary/การเงิน&q=026277&maxItems=20&skipCount=0
Authorization: Bearer <accessToken>

9. Search documents แบบชื่อไฟล์ตรงตัว

GET http://localhost:3001/user-api/alfresco/documents/search?folderPath=/Sites/tg-saving/documentLibrary&exactName=23017_116969.pdf&maxItems=20&skipCount=0
Authorization: Bearer <accessToken>

10. Get document location

แบบแนะนำ query id

GET http://localhost:3001/user-api/alfresco/documents/location?id=DOCUMENT_ID
Authorization: Bearer <accessToken>

แบบ route เก่า

GET http://localhost:3001/user-api/alfresco/documents/DOCUMENT_ID/location
Authorization: Bearer <accessToken>

11. Open file

GET http://localhost:3001/user-api/alfresco/documents/DOCUMENT_ID/content?name=file.pdf
Authorization: Bearer <accessToken>

ถ้าเรียกจาก frontend ต้องใช้ fetch พร้อม Bearer token แล้วเปิดด้วย Blob URL เพราะ window.open แนบ Authorization header ไม่ได้

12. Rename file

แบบแนะนำ query id

PATCH http://localhost:3001/user-api/alfresco/documents?id=DOCUMENT_ID
Authorization: Bearer <accessToken>
Content-Type: application/json

{
  "name": "new-file-name.pdf"
}

แบบ path parameter

PATCH http://localhost:3001/user-api/alfresco/documents/DOCUMENT_ID
Authorization: Bearer <accessToken>
Content-Type: application/json

{
  "name": "new-file-name.pdf"
}
